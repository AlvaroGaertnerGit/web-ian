# Service description (Particulares / Empresas / Abogados / Seguros / Investigación digital)

Only write a service the firm actually offers — `CLAUDE.md` §7 and §28:
never invent a service category. If unsure whether a service is real,
ask instead of guessing.

## Shape

1. **What it is** — one sentence, plain language, no jargon a
   non-specialist wouldn't know.
2. **Who it's for / typical situations** — a short list of concrete
   situations (from `CLAUDE.md` §7's real categories only), not vague
   "many different cases".
3. **What the client receives** — report, evidence type, chronology —
   only what can legally/technically be delivered (`CLAUDE.md` §11
   "Evidence"). Never promise a specific evidentiary outcome.
4. **Next step** — link to contact/CTA, no separate hard-sell paragraph.

## Do

- Ground every situation in the real category list (infidelidad,
  investigaciones familiares, custodia, fraude, bajas laborales,
  competencia desleal, siniestros, localización de personas, etc. —
  only the ones this firm actually provides).
- State legal grounding plainly when relevant: "dentro del marco legal
  vigente", "con interés legítimo acreditado" — these are reassurances,
  not disclaimers to bury in fine print.
- Keep paragraphs short — this is scanned, not read linearly.

## Don't

- Don't describe the *method* in a way that implies illegal access
  (hacking, phone/account access, message interception) — flag anything
  like this to `legal-guardrails` before it ships.
- Don't promise the investigation will find what the client hopes for.
- Don't pad with generic corporate language to make a short, honest
  service description feel longer.

## Example rewrite

> Generic: "Ofrecemos un servicio integral de investigación adaptado a
> todas tus necesidades con los más altos estándares de calidad."

> Specific: "Investigamos infidelidades mediante seguimiento discreto y
> documentación fotográfica y en vídeo, dentro del marco legal vigente.
> El resultado es un informe de investigación que puedes utilizar para
> tomar una decisión informada."
